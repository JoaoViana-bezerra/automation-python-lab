# Automation Python Lab

Coleção de projetos desenvolvidos em Python com foco em automação de processos, tratamento de dados, integração com APIs e geração de relatórios.

## Objetivo

Demonstrar aplicações práticas de Python para redução de tarefas manuais e melhoria de processos.

## Projetos

| Projeto | Descrição | Tecnologias |
|---|---|---|
| File Organizer | Organização automática de arquivos | Python |
| Excel Report Automation | Tratamento e geração de relatórios | Python, Pandas, OpenPyXL |
| API Data Collector | Coleta e tratamento de dados de APIs | Python, Requests |
| CSV Data Cleaner | Limpeza e padronização de dados | Python, Pandas |
| Report Generator | Geração automática de relatórios | Python |
